# RHI — упрощённый ПК-гейминг

RHI — настольное приложение, управляющее HDR-модами, ReShade, ограничителями FPS, DLSS/Streamline и не только во всей вашей библиотеке ПК-игр. Само находит игры из 8 магазинов и умеет ставить всё в один клик. Разработано RankFTW.

## Что умеет

- Само находит игры в Steam, GOG, Epic, EA, Ubisoft, Xbox/Game Pass, Battle.net и Rockstar
- Определяет движок каждой игры (Unreal Engine с версией, Unity, RE Engine) и графический API автоматически
- Установка, обновление и удаление ReShade, RenoDX, ReLimiter, Display Commander, OptiScaler, RE Framework, Luma Framework и DXVK в один клик
- Управление версиями DLSS и Streamline — независимая подмена SR, RR, FG; пресеты DLSS и масштаб рендеринга для каждой игры
- Управление ReBAR (Resizable BAR) для каждой игры с выбором режима и лимита размера
- 43 набора шейдеров с глобальным или индивидуальным выбором
- Перетаскивание модов, пресетов и архивов Luma
- Автоматическая настройка Engine.ini и reshade.ini для игр с нативным HDR UE-Extended
- Переопределения для каждой игры: имена DLL, режим шейдеров, режим аддонов, канал ReShade, вариант DXVK, аргументы запуска
- Запуск игр прямо из RHI с оверлеем Steam и учётом времени в игре
- Определение обновлений на Nexus Mods (без API-ключа)
- Автообновление приложения и манифеста

## Начало работы

1. Скачайте и запустите RHI — ваши игры появятся автоматически
2. Выберите игру и нажмите «Установить» у нужных компонентов (ReShade, RenoDX, ограничитель FPS)
3. Запустите игру, нажмите Home, чтобы открыть ReShade, зайдите в Add-ons и настройте RenoDX
4. Используйте «Обновить всё», чтобы поддерживать всю библиотеку в актуальном состоянии

RHI разворачивает преднастроенный `reshade.ini` с отключёнными ненужными аддонами и оптимальными настройками для HDR. Для игр UE-Extended настройки HDR в Engine.ini разворачиваются автоматически — вручную править INI не нужно.

## Советы

- Если игра не определилась — перетащите её .exe прямо в окно RHI
- Заглядывайте в индивидуальные кнопки «Инфо» — там заметки по настройке конкретных игр
- Кнопка «Конфиг» открывает папку Engine.ini игры напрямую
- Если ставите ReShade вручную (без RHI), отключите аддоны «Generic Depth» и «Effect Runtime Sync» — они тратят производительность без пользы при использовании RenoDX
- Для игр с нативным HDR UE-Extended: включите HDR-опцию в самой игре, если она есть
