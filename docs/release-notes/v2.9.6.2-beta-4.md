Changes since v2.9.6.2 Beta 3.

### Changes
- Game Overrides now goes away in RHI 2.9.6.3 (the note on it said 2.9.8). Each of its settings is already in its new place.
- **HSF XeMFG and Universal MFG Unlocker.** Installing HSF now asks whether to install Universal MFG Unlocker too on every RTX card, RTX 50 included, since HSF's new XeMFG engine relies on it for 3x to 6x. Picking XeMFG in HSF's ⚙ also offers to install Universal MFG Unlocker right there when the game doesn't have it (XeMFG needs it for 3x to 6x on every RTX card, RTX 50 included). In 64-bit DirectX 12 games RHI installs it as version.dll, the only name HSF 0.10 loads it under there, instead of asking for a name.

### Bug Fixes
- Fixed HSF 0.10 showing PROBLEM: "ReShade's Generic Depth add-on is off, so DLSS-G gets no depth". RHI's ReShade settings turn Generic Depth off by default; it now stays on in every game with HSF (games that already have HSF get it at RHI's next start), and goes back off when HSF is removed.
- Fixed iMMERSE LaunchPad sometimes being below HSF's effects in a new HSF install until RHI next started with the game closed: installing HSF now puts LaunchPad at the top of the game's ReShade preset straight away.
- Fixed removing HSF leaving HSF_safe_try.ini behind in the game folder (HSF's logs are kept).
