# RHI v2.0.0 — руководство по новым возможностям

Обзор всех крупных нововведений v2.0.0 и как ими пользоваться.

---

## Переопределения профиля NVIDIA

Крупнейшее пополнение в v2.0.0. Новый раздел под «Переопределениями игры» на панели игры даёт управление настройками профиля драйвера NVIDIA для каждой игры — без NVIDIA Profile Inspector.

### Строка DLSS / Streamline

Видна для любой игры, у которой обнаружены DLL DLSS или Streamline.

**Подмена версий:**
1. Выберите игру с установленным DLSS
2. Откройте список версий для SR, RR, FG или Streamline
3. Выберите любую версию — при отсутствии в кеше она скачается по требованию
4. DLL игры подменяется немедленно
5. Пункт `(Default)` возвращает оригинал

**Пресеты:**
1. Откройте список пресетов (под версиями) для SR, RR или FG
2. Выберите пресет (SR: J/K/L/M, RR: D/E, FG: A/B)
3. Применяется мгновенно к профилю драйвера NVIDIA — перезапуск игры не нужен

**Масштаб рендеринга:**
1. Откройте список «Масштаб рендеринга» для SR или RR
2. Выберите процент (33–100%) или именной пресет (DLAA, Quality и т.д.)
3. Принудительно задаёт внутреннее разрешение рендеринга DLSS для этой игры

**Быстрое применение:**
1. Откройте Настройки → DLSS и Streamline по умолчанию → «Настроить значения по умолчанию»
2. Задайте предпочитаемые версии, пресеты и масштабы рендеринга
3. В любой игре нажмите «Быстрое применение» — все значения по умолчанию применятся одним кликом

### Строка настроек драйвера

Управляет настройками профиля драйвера NVIDIA для каждой игры. Требует режима администратора (см. ниже).

| Колонка | Что можно менять |
|---------|------------------|
| VSync | Режим, управление разрывами, Low Latency (выкл/вкл/Ultra) |
| Smooth Motion | Включение, разрешённые API, Flip Pacing |
| Питание | Режим питания (Adaptive/Optimal/Max Performance) |
| ReBAR | Включение (выкл/вкл/глобально), режим (Standard/Optimized), лимит размера |

Все изменения мгновенны — записываются прямо в профиль драйвера NVIDIA игры.

## Режим администратора

Некоторые настройки NVIDIA (ReBAR, Low Latency Ultra, API Smooth Motion) требуют прав администратора.

**Как включить:**
1. Откройте Настройки → Данные и пользовательские файлы
2. Переведите «Режим администратора» в положение **Вкл**
3. Подтвердите разовый запрос UAC
4. Теперь RHI будет сам запускаться с повышенными правами — больше никаких запросов UAC

**Как отключить:**
1. Верните «Режим администратора» в **Выкл** — назначенное задание будет удалено

Без повышенных прав строка настроек драйвера затемняется с предупреждением.

## Мульти-генерация кадров (MFG)

Управление мульти-генерацией кадров NVIDIA для каждой игры. Только RTX 50-я серия (Blackwell).

**Как пользоваться:**
1. Выберите игру, у которой определена генерация кадров
2. Нажмите кнопку «Мульти-генерация кадров» под колонкой FG
3. Выберите режим:
   - **Фиксированный** — постоянный множитель кадров (2x–6x)
   - **Динамический** — адаптивный множитель с целевой частотой кадров
4. Для динамического режима задайте целевой FPS из пресетов лимитов VRR (подогнаны под распространённые частоты мониторов) или введите любое своё значение

**Требования:** GPU RTX 50-й серии, драйвер 572.16+ (фиксированный) или 595.97+ (динамический).

## DLSS и Streamline по умолчанию + быстрое применение

Настройте предпочитаемые параметры один раз — применяйте к любой игре мгновенно.

**Настройка:**
1. Откройте Настройки → DLSS и Streamline по умолчанию → «Настроить значения по умолчанию»
2. Задайте предпочитаемые версию, пресет и масштаб рендеринга для каждого компонента
3. Оставьте «По умолчанию (не менять)», чтобы пропустить компонент

**Использование:**
1. Выберите любую игру с DLSS/Streamline
2. Нажмите «Быстрое применение» в строке DLSS/Streamline
3. Все заданные значения применятся одним кликом (докачиваются по требованию)

---

## Глобальные настройки NVIDIA

Общесистемные настройки NVIDIA, влияющие на все игры. Находятся на странице настроек.

| Настройка | За что отвечает |
|-----------|-----------------|
| Размер кеша шейдеров | Сколько места на диске драйвер отводит под кеш шейдеров |
| Предкомпиляция шейдеров | Агрессивность фоновой компиляции шейдеров |
| Режим G-Sync | Выкл / только полноэкранный / полноэкранный+оконный |
| Предпочитаемая частота обновления | Настройка игры / наивысшая доступная |
| Глобальный ReBAR | Вкл/выкл + лимит размера (для всех игр) |
| Экранный индикатор DLSS | Текстовый оверлей NVIDIA DLSS в углу игр |

Настройки ReBAR требуют режима администратора.

## Экспорт / импорт профилей

Резервное копирование индивидуальных настроек профилей NVIDIA и их восстановление после обновлений драйвера.

**Экспорт:**
1. Откройте Настройки → Глобальные настройки NVIDIA → «Экспортировать профили»
2. Все индивидуальные + общие настройки сохранятся в `%LocalAppData%\RHI\nvidia_profiles_backup.json`

**Импорт:**
1. Нажмите «Восстановить профили»
2. Отсутствующие профили будут созданы, связи с exe зарегистрированы, все настройки восстановлены

**Сбросить всё:**
1. Нажмите «Сбросить профили всех игр» (кнопка с красной обводкой)
2. Подтвердите в диалоге предупреждения
3. ВСЕ индивидуальные И общие настройки NVIDIA будут сброшены до заводских

## Lilium HDR DXVK

HDR-форк DXVK теперь использует слой Vulkan ReShade в DX9-играх, включая HDR-шейдеры SM5, которые не работают в DX9-режиме.

**Как пользоваться:**
1. Выберите игру на DX8/DX9/DX10
2. В списке DXVK (Переопределения игры) выберите «Lilium HDR»
3. DXVK установится с включёнными апгрейдами HDR-цепочки обмена
4. Появится список «Пресет Lilium HDR» — выберите агрессивность HDR-апгрейдов:
   - **Safest** — только цепочка обмена (по умолчанию, ~100% совместимость)
   - **2nd Safest** — добавляет апгрейд буферов
   - **Slightly Unsafe** → **Experimental** — постепенно добавляет апгрейды целей рендеринга

Смена пресета сразу перезаписывает `dxvk.conf` — переустановка не нужна.

**При удалении:** ReShade автоматически возвращается как локальная DLL.

## Массовое развертывание DLSS и Streamline

Обновление версий и пресетов DLSS/Streamline сразу в нескольких играх.

**Как пользоваться:**
1. Откройте Настройки → «Массовое развертывание»
2. Отметьте игры в чек-листе (выбираются все; компоненты v1.x пропускаются индивидуально)
3. Выберите версии для SR, RR, FG и Streamline (или «None», чтобы пропустить)
4. Выберите пресеты для SR, RR, FG
5. При желании включите «Автосоздание профилей NVIDIA»
6. Нажмите «Развернуть» — прогресс показывается по каждой игре

Игры, уже находящиеся на выбранной версии, пропускаются автоматически.

## Простой вид (бывший компактный)

Вид по умолчанию при свежей установке. Постраничная раскладка из 3 страниц:

- **Страница 1** — компоненты (информация об игре, кнопки установки)
- **Страница 2** — переопределения игры (имена DLL, шейдеры, аддоны, DXVK, канал RS)
- **Страница 3** — переопределения профиля NVIDIA + управление

Для перехода между страницами используйте стрелки по бокам.

## Переопределение имени DLL в режиме Luma

Раньше блокировалось при активном Luma. Теперь можно переименовать DLL ReShade (`dxgi.dll`) в любое своё имя даже в режиме Luma — полезно для игр, требующих конкретное имя DLL.

## Восстановление значений профиля (для каждой игры)

В строке настроек драйвера в разделе переопределений профиля NVIDIA любой игры:

1. Нажмите «Восстановить значения по умолчанию»
2. Подтвердите предупреждение
3. Профиль NVIDIA этой игры будет сброшен до заводских (также восстанавливаются DLL DLSS/SL)

---

## Определение переопределения драйвера DLSS

Когда в NVIDIA App включены «Latest DLL» или «Use recommended preset»:
- Затронутые списки затемняются с текстом «⚠ Активно переопределение драйвера»
- Подсказки объясняют, как отключить это в NVIDIA App
- «Быстрое применение» пропускает переопределённые компоненты

---

## Обновления через манифест

Ряд функций теперь обновляется серверно, без релиза приложения:
- **Наборы шейдеров** — добавление, удаление, смена ссылок
- **Пресеты DLSS** — добавление новых пресетов по мере выхода от NVIDIA
- **Паки аддонов** — добавление, отключение, обновление записей
- **Ссылки компонентов** — перенаправление загрузок при переезде репозиториев

Всё это происходит автоматически при каждом запуске — от пользователя ничего не требуется.

## Советы

- **Режим администратора рекомендуется**, если нужен полный контроль над настройками драйвера (ReBAR, Low Latency Ultra, Smooth Motion)
- **Экспортируйте профили** перед обновлениями драйвера — NVIDIA сбрасывает пользовательские профили при каждой крупной установке драйвера
- **Быстрое применение** — самый быстрый способ настроить новую игру: задайте значения один раз и штампуйте где угодно
- **Значения лимитов VRR** в списке целевого FPS DMFG рассчитаны под распространённые частоты мониторов — выберите совпадающий с вашим дисплеем для оптимального вывода кадров
- **Пресет Lilium HDR «Safest»** рекомендуется, если точно не знаете, что вашей игре нужны апгрейды целей рендеринга
