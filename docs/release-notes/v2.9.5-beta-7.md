## v2.9.5 Beta 7

Changes since v2.9.5 Beta 6.

### New
- Backup and restore, for a reformat or a new PC (Settings › Tools & Maintenance › Backup and restore). A backup keeps RHI's settings and every per-game choice, your presets, custom builds and artwork, what RHI installed in each game, the games' config files (reshade.ini and its preset, relimiter.ini, OptiScaler.ini and others) and your NVIDIA driver settings. Choose a folder that survives a reformat (another drive, OneDrive, a USB stick) and RHI backs up automatically, at most once a day and only when something changed, keeping the newest 5. To restore, use Restore from a backup in Settings, or the new option on the first-run screen of a fresh install. Once your games are found, RHI lists what was installed in each one, all ticked, and installs it again with your restored settings. Config files go back too, except ones already in the game folder. Not included: your GitHub token and API keys, and extras such as HSF or RTX Encore, which you install again yourself (their settings are kept).
- ReLimiter v4 can show NVIDIA PC Latency (PCL) on its overlay. The new PC Latency (PCL) button in Settings › Components › ReLimiter gives Windows the permission it needs (once for your whole Windows account; sign out and back in afterwards), and from then on RHI turns PCL on in each game it installs v4 in.

### Changes
- The first-run screen is redesigned: one page with the ReShade choice, an optional GitHub token (with a link to make one; RHI checks and saves it before its first downloads, so a new install starts with 5,000 GitHub requests an hour instead of 60), and Restore from a backup.

### Bug Fixes
- Fixed selected ReShade add-ons and OptiScaler's Streamline files never coming back after Purge staging files or a restore: RHI skipped them in every game instead of downloading them again.
- Fixed GITC Uplift's and HSF's shaders being removed from games on the first launch after Purge staging files or a fresh RHI folder. They came back on the next launch.
- Fixed DLDSR and DSR smoothness errors only saying "check logs". When RHI isn't running as administrator, which DLDSR changes need, the message now says so and points to Admin Mode.
