## v2.9.6 Beta 8

Changes since v2.9.6 Beta 7.

### New
- **Experimental section.** A new section for features that are new and not fully tested yet, in Classic+, Tabs and Spotlight (between Neural Rendering and Management). The first is **URTI** by Skynizz, a ReShade add-on that adds ray-traced reflections to DirectX 12 games that don't have them: puddles, wet streets, windows and polished floors. RHI installs the add-on, its urti.ini and its effects, turns the URTI effect on in the game's ReShade preset and keeps ReShade's Generic Depth add-on on for it, and keeps it updated. F7 turns it on and off in the game, and URTI's ⚙ has its urti.ini settings (start on, shadow rays, calibration, capture length, reflection F0, jitter correction, UI snapshot, sunlight measuring and a protected UI zone), with a button to go back to RHI's profile. It needs a 64-bit DirectX 12 game, ReShade 6.8 or newer with add-on support, and a ray tracing graphics card (NVIDIA RTX 20 or newer, AMD RX 6000 or newer). It's only tested in Red Dead Redemption 2 so far, and it doesn't draw while HSF is installed in the same game (RHI warns you). Single player only: never use it online.
- **FrameWarp in Experimental.** FrameWarp (XPAR) by xPoiler moves the camera at your display's refresh rate whatever frame rate the game renders at: every refresh re-projects the game's newest frame to where the camera is now, and its own frame generation shows moving characters at the refresh rate too. DirectX 12, DirectX 11 and Vulkan games, 64-bit, using the game's DLSS or FSR when it has them. RHI installs the add-on, its presenter and XPAR.addonfx, keeps them updated, adds the Streamline setting Unreal Engine games need to Engine.ini, and for Unreal Engine games with DLSS adds the launch options FrameWarp needs (-slforcetagging -slviewextension) to RHI's launch arguments (add them to Steam's launch options too if you start the game there), and keeps ReShade's Generic Depth add-on on for it (not in Red Dead Redemption 2, where FrameWarp says to keep it off). Installing warns first about frame rate limiters (ReLimiter, Display Commander, the NVIDIA limit, which it can turn off for the game), hardware-accelerated GPU scheduling and the Visual C++ runtime; installing ReLimiter or Display Commander in a FrameWarp game warns too. On NVIDIA cards, its ⚙ can add NVIDIA Latewarp (Reflex 2 Frame Warp), downloaded only when it matches NVIDIA's file. Run games borderless and use its XPAR tab in ReShade. Single player only.
