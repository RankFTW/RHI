### [ ] N1. Two generic RenoDX add-ons (220 MB together) are downloaded in full on most checks

**File:** `RenoDXCommander/Services/ModInstallService.cs`, `CheckForUpdateByDownloadAsync`.

**Problem (Measured):** the log shows `renodx-ue-extended.addon64 … changed or server ignored ETag — downloading` at 11:28:17, 12:28:18 and 13:28:16, and the same for `renodx-unityengine.addon64` at 11:28:20 and 12:28:21. The files are 65 MB and 155 MB, and neither had changed. This step is about half of the hourly check.

**Cause:** these files are on GitHub Pages. Its ETag is `"<modified time in hex>-<size in hex>"`, and its servers disagree on the time by a second or two for the same file. Three requests for one URL returned `"6b04d248-3e10000"`, `"6b04d248-3e10000"` and `"6b04d24a-3e10000"`; RHI had stored `"6b04d249-3e10000"`. So `If-None-Match` only matches when the request happens to reach the same server.

**Current code:**

```csharp
var responseETag = resp.Headers.ETag?.ToString();
if (conditional)
    CrashReporter.Log($"[ModInstallService.CheckForUpdateByDownloadAsync] '{Path.GetFileName(localFile)}' changed or server ignored ETag — downloading");
```

**Change:**

1. Add a helper to the class:
   ```csharp
   // GitHub Pages ETag = "<mtime hex>-<size hex>"; its servers differ by a second or two for one file.
   internal static bool IsSamePagesBuild(string? a, string? b)
   {
       static bool Parse(string? s, out long t, out long size)
       {
           t = size = 0;
           if (string.IsNullOrEmpty(s)) return false;
           s = s.Trim(); if (s.StartsWith("W/")) s = s[2..];
           var p = s.Trim('"').Split('-');
           return p.Length == 2
               && long.TryParse(p[0], System.Globalization.NumberStyles.HexNumber, null, out t)
               && long.TryParse(p[1], System.Globalization.NumberStyles.HexNumber, null, out size);
       }
       return Parse(a, out var ta, out var sa) && Parse(b, out var tb, out var sb) && sa == sb && Math.Abs(ta - tb) <= 5;
   }
   ```
2. Right after `var responseETag = …`, before the existing log line:
   ```csharp
   if (conditional && IsSamePagesBuild(known!.ETag, responseETag))
   {
       CrashReporter.Log($"[ModInstallService.CheckForUpdateByDownloadAsync] '{Path.GetFileName(localFile)}' unchanged (same size, time within 5 s)");
       return false;   // the using disposes the response; the body is never read
   }
   ```
