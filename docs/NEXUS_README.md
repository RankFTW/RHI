[center][size=6][b]RHI — ReShade HDR Installer[/b][/size]

[i]Автоматический HDR-моддинг, управление DLSS и настройками драйвера NVIDIA для всей вашей библиотеки ПК-игр.[/i][/center]

RHI сканирует все ваши игры из Steam, Epic, GOG, Xbox Game Pass, EA, Ubisoft, Battle.net, Rockstar и itch.io — а затем делает всё остальное в один клик.

[size=5][b]HDR для каждой игры[/b][/size]

[b]Именные моды (RenoDX)[/b] — сотни HDR-модов под конкретные игры, которые подбираются и устанавливаются автоматически. Если для вашей игры мод есть, RHI его найдёт и будет поддерживать актуальным.

[b]Игры на Unreal Engine[/b] — каждая UE-игра получает HDR через аддон UE-Extended. RHI сам записывает правильные настройки Engine.ini и конфигурацию reshade.ini. Вам не придётся трогать ни один ini-файл.

[b]Luma Framework[/b] — у каждой игры на DX11 Unreal Engine в библиотеке автоматически появляется вариант Luma. Игровые ключи Engine.ini, аргументы запуска и настройки TAA применяются из вики при установке без каких-либо ручных шагов.

[b]DX9 / старые игры[/b] — DXVK + Lilium HDR добавляет вывод scRGB HDR в игры без нативного HDR-пути.

[b]Всё остальное[/b] — RenoFX HDR Toolkit превращает SDR в HDR для любой оставшейся игры.

[size=5][b]Заменяет установщик ReShade[/b][/size]

RHI ведёт ReShade от начала до конца. Без ручных загрузок, без гаданий с именами DLL, без правки ini.

[list]
[*]Определяет графический API каждой игры автоматически и даёт DLL правильное имя (dxgi.dll, d3d9.dll, opengl32.dll)
[*]Свежие стабильные и ночные сборки всегда наготове — загружаются при запуске приложения
[*]Каналы сборки для каждой игры: Stable, Nightly, Custom, Legacy или No Addons — свободно комбинируются по библиотеке
[*]Vulkan-игры обслуживаются через глобальный implicit-слой — установка в один клик
[*]Обнаружение чужих DLL: предупреждает перед перезаписью DXVK, Special K или ENB
[*]Сам ведёт reshade.ini — горячие клавиши, путь к скриншотам, пиковая яркость и пути DLSS настроены
[/list]

[size=5][b]DLSS 5 и нейронный рендеринг[/b][/size]

[b]DLSS5 Feeder[/b] — один клик разворачивает весь конвейер нейронного рендеринга: аддон-потребитель DLSS5, nvngx_dlssnr.dll, преднастроенный пресет ReShade и нужные наборы шейдеров. Сам выбирает подходящий метод для вашей игры (DX11, DX12, 32 бита).

[b]NR Cost Scaler[/b] — запускает нейронный рендеринг с затратами 75% по умолчанию. Включите перед установкой метода — развернётся вместе с ним автоматически.

[b]ShortFuse DLSS Tool[/b] — альтернативная реализация нейронного рендеринга для игр на DX12.

[line]

[size=5][b]Менеджер DLSS и Streamline[/b][/size]

Каждая игра с NVIDIA получает полноценную панель управления DLSS.

[list]
[*]Подмена версий SR, RR, FG и Streamline для каждой игры — любая версия с 2.x до актуальной
[*]Оригинальные DLL резервируются автоматически и восстанавливаются в любой момент
[*]Пресеты (J/K/L/M для SR, D/E для RR, A/B для FG) записываются прямо в профили драйвера NVIDIA — Profile Inspector не нужен
[*]Переопределение масштаба рендеринга — принудительное разрешение рендеринга от 33% до 100% для каждой игры
[*]Переопределение NVIDIA — включайте внедрение «Latest DLL» драйвером для каждого компонента прямо из списка версий
[*]Массовое развертывание — применить версии, пресеты и масштабы рендеринга ко всей библиотеке разом
[*]Автообновление SR, RR и FG — по желанию, для каждой игры
[/list]

[size=5][b]Мульти-генерация кадров[/b][/size]

[b]RTX 40 MFG Unlock[/b] — включает множители MFG выше 2x (до 6x) на RTX 40-й серии через Ultimate ASI Loader. Установка в один клик из раздела «Дополнения».

[b]MFG на RTX 50-й серии[/b] — настройка фиксированного или динамического режима, количества кадров (2x–6x) и динамической целевой частоты из панели DLSS.

[size=5][b]OptiScaler[/b][/size]

[list]
[*]FSR4 / FSR3 / XeSS в играх только с DLSS. Генерация кадров на GPU AMD и Intel.
[*]Каналы Stable и Nightly выбираются для каждой игры
[*]Преднастроенные INI-шаблоны под GPU (NVIDIA, AMD+DLSS, AMD без DLSS) — редактируются пользователем и не перезаписываются
[*]Развертывание Streamline + DLSS Enabler для каждой игры в связках Nightly FG
[*]Полные настройки генерации кадров в шестерёнке: FG Input, FG Output, замена Nvngx, HUD Fix
[*]OptiPatcher разворачивается автоматически и тихо обновляется
[/list]

[size=5][b]Ограничители FPS[/b][/size]

[b]ReLimiter[/b] — прецизионный вывод кадров с предиктивной задержкой сна, фазо-заблокированными таймингами, учётом VRR и адаптивным pacing под DLSS FG. Самый точный из доступных ограничителей FPS.

[b]Display Commander[/b] — альтернативный ограничитель с поддержкой и 32-, и 64-битных игр.

Оба ставятся как аддоны ReShade и обновляются автоматически.

[size=5][b]Управление профилями драйвера NVIDIA[/b][/size]

RHI записывает настройки драйвера напрямую через NvAPI — внешние инструменты не нужны.

[*]Режим VSync и управление разрывами
[*]Low Latency (выкл / вкл / Ultra)
[*]Smooth Motion (RTX 40+) — включение, разрешённые API, Flip Pacing
[*]Режим управления питанием
[*]Переключатель G-Sync для каждой игры
[*]ReBAR — выкл / вкл / авто, режим, лимит размера
[*]RTX HDR — включение с пиковой яркостью, контрастом, насыщенностью, средним серым и устранением бандинга
[*]Пресеты DLSS и переопределение масштаба рендеринга
[/list]

[b]Глобально (все игры):[/b]
[list]
[*]Кеш шейдеров, режим G-Sync, предпочитаемая частота обновления, глобальный ReBAR, лимит FPS
[*]Digital Vibrance для каждого дисплея — автоматически восстанавливается при каждом запуске приложения
[/list]

[b]Экспорт / импорт[/b] — резервное копирование всех индивидуальных настроек NVIDIA в файл. Восстановите всё после переустановки драйвера в один клик.

[size=5][b]Автопереключение HDR[/b][/size]

Включает Windows HDR при запуске игры и выключает при её закрытии. Работает со Steam, Epic, Xbox Game Pass и прямым запуском exe. Переопределяется для каждой игры кнопкой HDR рядом с «Запустить».

[size=5][b]46 наборов шейдеров[/b][/size]

Все нужные наборы шейдеров, управляемые из одного окна.

[b]Необходимые:[/b] Lilium HDR Shaders — нужны для HDR-тонмаппинга.

[b]Рекомендуемые:[/b] PumboAutoHDR, crosire reshade-shaders, MaxG2D Simple HDR, шейдеры clshortfuse, RenoFX HDR Toolkit, smolbbsoop shaders.

[b]Дополнительные:[/b] iMMERSE, qUINT, OtisFX, SweetFX, Prod80, CRT-Royale, VRToolkit, ZenteonFX, QD-OLED APL Fixer, LumaBoost, Glamarye Fast Effects и ещё 28 наборов.

Наборы выбираются глобально или для каждой игры. Внутри любого набора можно отметить отдельные файлы шейдеров. Сохраняйте подборки как именные профили и экспортируйте в zip, чтобы поделиться прямо в Discord.
